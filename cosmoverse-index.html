Production and deployment package

10-line project summary

  1. Single-file cinematic HTML experience.
  2. Responsive mobile-first interface.
  3. Three.js starfield with Canvas2D fallback.
  4. Four persistent visual themes.
  5. English, Persian and Arabic support.
  6. RTL-aware layout and typography.
  7. Accessible navigation and dialogs.
  8. SEO, Open Graph and JSON-LD included.
  9. No framework or build process required.
  10. Ready for static hosting and CDN delivery.

Publishing guide

Upload index.html and the generated support files to your domain root, replace example URLs with your production domain, add a 1200×630 Open Graph image, enable HTTPS and submit sitemap.xml to search engines.
